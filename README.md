# AI Parking Assist

自然言語の要望を小さなAIが分類し、車高制限と空車状態を満たす区画へ台車が移動します。
Physical AI 応用1 2026 最終課題用の、Windowsローカルで動く最小構成です。

## この作品でできること

| 要望・車高 | 動作 |
|---|---|
| 「入口の近いところをお願いします」・1.50m | 区画Aへ移動・停止 |
| 「空いていればどこでも大丈夫です」・1.50m | 近い区画を残す運用ルールでBへ移動・停止 |
| 入口近くを希望・2.00m | Aは高さ制限で除外、Bへ移動・停止 |
| 入口近くを希望・2.20m | 対応するCは満車のため発進しない |

車高は数値入力で、AIは「入口近く／場所の指定なし」だけを分類します。
区画3つ・差動二輪の台車1台・固定通路を使用し、各ケースは同じ初期状態から始めます。

## 今回のPCで起動する

`start.cmd`をダブルクリックし、画面の「4ケース自動デモ」を押します。
この作業環境では専用Python環境が準備済みです。DockerやWSLの起動は不要です。
「実行」は入力された要望と車高で1ケース実行します。区画の満車チェックも変更できます。

## 別のPC・Dドライブのコピーで初めて動かす

1. Windows 64bit版のPython 3.11を用意する。
2. コードを任意の作業フォルダへ展開する（例：Dドライブの専用フォルダ）。
3. `setup.cmd`をダブルクリックする。初回だけネット接続が必要。
4. 完了したら`start.cmd`をダブルクリックする。

`setup.cmd`はこのフォルダ内に`.venv`・`.pip-cache`・`.tmp`を作り、固定バージョンを導入します。
既存のPythonパッケージを変更しません。容量は検証時で環境約221MB＋キャッシュ約60MBです。
インストール先のフォルダに書込み権限が必要です。

手動セットアップの場合：

```powershell
py -3.11 setup_env.py
.\.venv\Scripts\python.exe -X utf8 app.py
```

## 動画を自動生成する

`record.cmd`をダブルクリックします。画面録画操作は不要です。
`artifacts/parking_demo.mp4`に、説明画面を含む約1分37秒の1280×720・30fps動画を保存します。
物理シミュレーションを再実行して描画するため、生成時間はPC性能に依存します。
映像はシミュレーション時間に対して等速です。ナレーションはなく、日本語の画面説明を使います。
GUI表示は描画速度により実時間より遅くなる場合があります。

```powershell
.\.venv\Scripts\python.exe -X utf8 demo.py --record
```

## AI・判断・制御の分担

```text
日本語の要望 ─→ 文字1/2-gram + ナイーブベイズ ─→ 希望のラベル
                                                   ↓
数値で入力した車高 + 既知の区画情報 ─────────→ 区画選択
                                                   ↓
                                    固定経由点を追う走行制御
                                                   ↓
                                 MuJoCoの左右輪アクチュエータ
```

- AIは自作の例文48件から文字特徴の頻度を学習します。固定の単語分岐ではありません。
- 起動時にローカルで学習するため、モデルのダウンロードや外部APIキーは不要です。
- 車高と満車は通常のロジックで判定します。AIは区画情報を書き換えません。
- 「指定なし」では入口に近い区画を残す運用ルールを適用します。
- 車輪に速度指令を与え、MuJoCoが接触・摩擦を含む運動を計算します。
- 動作中に台車の位置を直接書き換えていません。位置・向きはシミュレータから取得します。
- ROSノードやTopicは使用しません。各Pythonモジュールが直接データを渡します。

## 検証結果

- 9件の自動テストが成功。
- 評価例文12件中12件が正解。自作の少数例文での結果であり、汎用的な日本語理解の性能値ではありません。
- 走行3ケースは目標位置から0.10m以内へ到着。1秒間の停止確認も実施。
- 満車ケースでは移動命令を出さず、8秒間を検証（姿勢安定化による移動は約0.002m）。
- 検証ケースで静的障害物との接触は検出されませんでした。
- 詳細は動画生成時の`artifacts/run_results.json`と`artifacts/ai_evaluation.json`へ保存します。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest -v
.\.venv\Scripts\python.exe -X utf8 demo.py
```

動画を生成しない`demo.py`の結果は`artifacts/validation_results.json`に保存します。

## 対象範囲と制限

車高は仮想車両の論理条件で、台車の形状は変えていません。実車の積み下ろしやバック駐車は行いません。
画像認識、自己位置推定、動的障害物回避、複数台運行は対象外です。
AIの分類対象は2つの希望のみで、複雑な否定・複数要望・対象外の文では誤分類し得ます。
低い分類スコアや未知の特徴が多い入力は確認待ちにしますが、すべての誤解釈を防ぐ仕組みではありません。
実機の安全制御を評価した作品ではありません。
